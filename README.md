# QueryMind

AI-powered data analytics platform that lets users upload datasets, ask questions in natural language, and generate insights, charts, and SQL automatically.

## Features

- Upload CSV and Excel datasets
- Automatic dataset profiling
- Automatic dashboard generation
- Ask questions using natural language
- Generate SQL automatically
- View results in tables and charts
- Generate AI-powered insights
- Dark mode
- DuckDB and Exasol support
- Local AI support with Ollama

## Tech Stack

- React
- Vite
- FastAPI
- Python
- Pandas
- DuckDB
- Exasol
- Ollama
- Recharts
